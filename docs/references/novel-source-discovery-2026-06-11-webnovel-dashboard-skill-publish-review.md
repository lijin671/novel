## Absorbed Patterns

- `dashboard_task_quality_resume_gate`
  - Model `init -> plan -> write -> review -> repair -> query -> resume` as
    resumable tasks with named state, reports, backups, and quality panels.
  - Resume requires last accepted task, failed task, backup path, and next safe
    command before generation or repair.

- `webnovel_skill_suite_release_boundary_gate`
  - Treat public webnovel skill packs as stage maps, not installable upstream
    runtime.
  - Public release boundaries must exclude private rank snapshots, source cards,
    caches, generated bytecode, and local paths.

- `platform_voice_meme_emotion_gate`
  - Platform voice, meme energy, comment-section rhythm, and emotional-radar
    hints are register controls.
  - They cannot override canon, character voice, author intent, or safety rules.

- `truth_file_phase_dashboard_gate`
  - Truth files such as `current_state`, `resource_ledger`,
    `relationship_graph`, and `hooks` are canon ledgers.
  - Dashboard phases can propose task packages and writebacks, but accepted
    phase outputs are required before ledger mutation.

- `platform_publish_automation_boundary_gate`
  - One-click publish, browser automation login, and HTTP upload are release
    surfaces.
  - They require a separate publication safety packet and remain disabled during
    source intake.

- `multi_work_style_imitation_mode_gate`
  - Multi-work management must bind style imitation, manual continuation, and
    automatic continuation to the selected work id and mode contract.
  - Automatic mode must check character-setting collapse, plot memory loss, and
    rigid AI-style wording against accepted state.
