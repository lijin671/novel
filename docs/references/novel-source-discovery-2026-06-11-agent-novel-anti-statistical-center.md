## Reusable Patterns

1. Classify each chapter before drafting.
   The chapter should be routed as emotion, action, or function, then receive
   the smallest relevant checklist instead of one generic continuation prompt.

2. Track event cooldowns.
   Repeated reveal, fight, negotiation, rupture, setup, payoff, or quiet-beat
   patterns should be visible before the next chapter is accepted.

3. Add a visible-image contract.
   Before drafting, name the one image the reader should remember and the three
   promises this chapter must satisfy. After drafting, verify those promises.

4. Use reverse-brake pressure on non-final chapters.
   A continuation chapter should not resolve the central conflict too early.
   It should usually add at least one live unresolved question unless the author
   explicitly marks it as an ending or quiet exception.

5. For same-type creation, transform the method only.
   The new story can reuse chapter-type control and cooldown thinking, but not
   the source chapter-type sequence, event rhythm, visible-image motif, or
   promise order.
