# 网文拆书工具集 - 通用模板

本模板是一套完整的长篇网文分析工具，包含章节拆分、角色词频统计、主题分析、文风指纹计算、场景提取等功能。

## 目录结构

```
template/
├── config.json                       # 配置文件（角色、主题、12维度拆解项）
├── novel.txt                         # 你的小说原文（TXT 格式）
├── chapters/                         # 拆分后的章节（带标题名）
├── chapters_renamed/                 # 纯数字编号的章节
├── deconstruction/                   # 12维度拆解报告（手填分析内容）
├── reports/
│   ├── data_*.json                   # 批处理数据（运行 auto_analyze 生成）
│   ├── stylometric_quantitative.json # 量化文风指纹
│   ├── scene_extracts.txt            # 场景原文提取
│   ├── scene_extracts.json           # 场景 JSON 索引
│   └── cross_compare/                # 跨作品对比表（运行 cross_compare 生成）
└── *.py                              # 13 个分析脚本（见下方说明）
```

## 使用流程

### 第一步：准备
1. 将小说全文 TXT 放入 `novel.txt`
2. 编辑 `config.json`，填入角色名（含别名）、主题关键词、场景关键词

### 第二步：拆分章节
```bash
python split_chapters.py     # 按"第X章"拆分到 chapters/
python rename_chapters.py    # 重命名为纯数字编号到 chapters_renamed/
```

### 第三步：分析
```bash
python auto_analyze.py               # 批量提取角色/主题词频 → reports/data_*.json
python stylometric_quantitative.py    # 10项量化文风指纹 → reports/stylometric_quantitative.json
python scan_all.py                    # 全本概览扫描（角色出场、章节信息）
```

### 第四步：场景提取（可选）
```bash
python extract_scenes.py             # 提取 config.json 中配置的场景
python extract_all_scenes.py         # 完整版（含 JSON 索引）
```

### 第五步：修正与查看
```bash
python fix_dialogue.py               # 修正对话比例
python show_results.py               # 中文查看量化指纹
python display_results.py            # 英文查看量化指纹
python self_audit.py                 # 完整性自检
```

## 脚本列表

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `split_chapters.py` | 拆分原始文本为单章文件 | novel.txt | chapters/ |
| `rename_chapters.py` | 重命名为纯数字编号 | chapters/ | chapters_renamed/ |
| `auto_analyze.py` | 批量角色/主题词频提取 | chapters_renamed/ | reports/data_*.json |
| `stylometric_quantitative.py` | 10项量化文风指纹 | chapters_renamed/ | reports/stylometric_quantitative.json |
| `fix_dialogue.py` | 修正对话比例 | JSON文件 | 更新JSON |
| `scan_all.py` | 全本扫描分析 | chapters_renamed/ | 控制台输出 |
| `extract_scenes.py` | 提取经典场景原文 | chapters_renamed/ | reports/scene_extracts.txt |
| `extract_all_scenes.py` | 场景完整版+JSON索引 | chapters_renamed/ | reports/scene_extracts.* |
| `show_results.py` | 中文展示量化结果 | 量化JSON | 控制台输出 |
| `display_results.py` | 英文展示量化结果 | 量化JSON | 控制台输出 |
| `self_audit.py` | 项目完整性自检 | 全部文件 | 控制台输出 |
| `deconstruction_report.py` | 生成12维度拆解报告模板 | config.json | deconstruction/ |
| `cross_compare.py` | 跨作品对比表 | deconstruction/*.md | reports/cross_compare/ |

## 配置说明

编辑 `config.json`：

- **characters**：`{"角色名": ["别名1", "别名2"]}` 格式
- **themes**：`{"主题名": ["关键词1", "关键词2"]}` 格式
- **emotion_positive/negative**：情感分析用的正负面词汇
- **scene_keywords**：场景提取的章节文件名+关键词+上下文行数

## 全纬度补充拆解指南

完成一部作品的拆解后，如需跨题材迁移（现代→架空、都市→玄幻等），可按 **12 个标准维度** 补充拆解其他作品，最后整合为一套通用的创作工具箱。

### 12 维度拆解模板

每部作品按以下模板逐一拆解（使用 `deconstruction_report.py` 生成空白报告），最终可横向对比、交叉合并：

```
┌─────────────────────────────────────────────┐
│  D1 剧情结构    │  三幕/起承转合/开篇钩子      │
│  D2 节奏控制    │  爽点密度/高潮间隔/黄金三章   │
│  D3 人物体系    │  主角公式/女主原型/配角功能   │
│  D4 爽点类型    │  5种爽点的变体与创新          │
│  D5 金句体系    │  每章金句/对话名句/哲理句     │
│  D6 战斗/冲突   │  单挑/群战/战争的分镜         │
│  D7 世界构建    │  地理/历史/政治/经济          │
│  D8 力量体系    │  等级/能力/代价/突破          │
│  D9 对话技法    │  推进剧情/塑造性格/埋设伏笔   │
│  D10 环境描写   │  场景/服饰/器物/氛围          │
│  D11 伏笔/悬念  │  铺设方式/回收时机/误导手法   │
│  D12 情感线     │  感情节奏/CP模式/虐点甜点     │
└─────────────────────────────────────────────┘
```

### 使用流程

```bash
# 1. 生成空白拆解报告模板（交互式输入作品名）
python deconstruction_report.py

# 2. 手动填充 deconstruction/<作品名>_拆解报告.md 的 12 个维度

# 3. 重复步骤1-2，拆完 2 本以上即可对比
python cross_compare.py           # 生成跨作品对比表
```
